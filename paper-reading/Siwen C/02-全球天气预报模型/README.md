# 02 · 全球天气预报模型

**目标：** 看懂三种有代表性的气象 AI 路线。建议按下列顺序阅读：

1. [GraphCast — Learning skillful medium-range global weather forecasting](learning-skillful-medium-range-global-weather-forecasting.md) — 图结构与确定性中期预报。
2. [GenCast — Probabilistic weather forecasting with machine learning](probabilistic-weather-forecasting-with-machine-learning-gencast.md) — 概率预报与集合不确定性。
3. [ClimaX — A Foundation Model for Weather and Climate](climax-foundation-model-for-weather-and-climate.md) — 气象基础模型与跨任务适配。

**组会问题：** 三者的输入、输出、预测时效、训练数据、误差统计与泛化验证有什么差异？不要把不同数据集上的数值直接比较。
