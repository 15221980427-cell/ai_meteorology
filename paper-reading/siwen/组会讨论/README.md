## 组会讨论主线

- 训练集/测试集来自真实物理设备，不代表模型已经通过前瞻性现场实验。它们证明的是模型在留出历史数据上的预测能力。
- 雷达或激光雷达与塔架数据需要尽量做到同高度、同位置/代表性体积、同时间窗口，并记录质量控制和有效数据率。
- 风切变是跨高度差分量；风速误差、垂直分辨率和高度间偏差会直接传递到切变估计。风功率则通过非线性功率曲线响应风速误差。
- 对我们的项目，可先用历史观测做严格的时间外推测试，再冻结模型进入同步观测的前瞻性“影子运行”，最后再评估是否具备业务使用条件。
