## 手动上传方式

1. 打开本目录，在 GitHub 选择 **Add file → Upload files**；
2. 仅上传拥有公开分发许可的原文 PDF；否则保留 DOI / 开放获取地址即可；
3. 文件名使用英文、小写、连字符，例如 `wind-power-forecasting-deep-representation-survey.pdf`；
4. 上传后更新此表状态，并在相应文献笔记中补充相对链接 `../paper/xxx.pdf`。
